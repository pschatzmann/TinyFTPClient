Detailed Description

template<class ClientType>
class tinyftp::FTPClient< ClientType >

FTPClient Basic FTP access class which supports directory operations and the opening of files. Each open file or directory listing uses its own FTP session (command and data connection): idle sessions are reused. The files and iterators must not be used after the FTPClient has been destroyed.

Template Parameters
ClientTypeThe type of client to use for command and data connections. It should be a class that implements the Client interface.

Phil Schatzmann
