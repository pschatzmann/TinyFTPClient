Detailed Description

template<typename TServer, typename TStorage>
class tinyftp::FTPServer< TServer, TStorage >

Simple, extensible FTP server for Arduino using a templated server and storage backend.

Template Parameters
TServerServer type (e.g., WiFiServer)
TStorageStorage type (e.g., SDClass, fs::FS, CallbackFSClass). The header of the storage (e.g. SD.h) must be included before FTPServer.h

This class implements a basic FTP server supporting commands like USER, PASS, LIST, PWD, CWD, RETR, STOR, etc. File data is transferred over a separate data connection which is opened with PASV, EPSV (passive) or PORT (active). The server uses a pluggable storage backend for file and directory operations.

Up to FTP_SERVER_MAX_SESSIONS clients can be connected at the same time: doLoop() does not block, it processes one step (a command or a part of a transfer) of each connection. Each connection uses its own passive data port: dataPort + connection index.
