Detailed Description

CallbackFSClass File system which can be used as storage of the FTPServer: it does not store any files but logs each file operation and reports it to callbacks. Use the CallbackFS object, e.g.

FTPServer<WiFiServer, CallbackFSClass> ftpServer(21, &CallbackFS);

  • The operation callback is called for all operations: its result is the result of exists(), remove(), mkdir(), rmdir() and rename().
  • The optional list callback defines the directories and their entries.
  • The optional read callback provides the content of the files (get).
  • The optional write callback receives the uploaded files (put).

using tinyftp::CallbackFSClass::ReadCallback = std::function<int(const char *path, size_t pos, uint8_t *data, size_t len)>

Read callback: copies up to len bytes of the file starting at pos into data and returns the number of bytes (0 at the end of the file). If data is nullptr, it returns the file size (or 0 if unknown) or -1 if the file does not exist.

◆ WriteCallback

using tinyftp::CallbackFSClass::WriteCallback = std::function<bool(const char *path, const uint8_t *data, size_t len)>

Write callback: receives the next len bytes of the uploaded file. It is called with data == nullptr when the file is opened: return false to reject the upload.
