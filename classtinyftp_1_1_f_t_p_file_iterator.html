Detailed Description

FTPFileIterator The file name iterator can be used to list all available files and directories. We open a separate session for the ls operation so that we do not need to keep the result in memory and we don't lose the data when we mix it with read and write operations. The listed files use their own sessions.

Copies of an iterator share the same listing: it is ended when all entries have been read or when the last copy is destroyed.
