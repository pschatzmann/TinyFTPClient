Detailed Description

FTPFile A single file which supports read and write operations. This class is implemented as an Arduino Stream and therefore provides all corresponding functionality.

Copies of a file share the same transfer: the transfer is ended when close() is called or when the last copy is destroyed. A file must not be used after the FTPClient which created it has been destroyed.
